### FR-02: [상황 정보(날씨 및 위치) 자동 수집]

- **설명**: 시스템은 음악 생성 시 사용자의 현재 위치와 날씨 정보를 자동으로 가져와 앱 화면과 AI 입력 데이터에 유기적으로 반영한다.
- **수용 조건**:
  - [ ] 위치 권한 획득 후 사용자의 현재 위도·경도 좌표를 기반으로 지역 정보를 가져와야 한다.
  - [ ] 외부 날씨 API 연동을 통해 현재 날씨 정보를 실시간으로 파악할 수 있어야 한다.
  - [ ] 파악된 날씨/위치 정보에 따라 메인 화면의 배경색이나 추천 장르가 동적으로 변경되어야 한다.
